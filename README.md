# Hazem Saed Portfolio

A clean, responsive static portfolio.

## Run
Open `index.html` directly in your browser.

## Files
- `index.html` — page structure and content
- `styles.css` — design and responsive layout
- `script.js` — light interactions
- `assets/hazem-saed.jpg` — portrait
- `assets/Hazem_Saed_CV.docx` — downloadable CV

## Deploy
You can deploy this folder directly to:
- GitHub Pages
- Netlify
- Vercel (static site)
